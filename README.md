# 方塊重組｜畢業專題

以純 HTML、CSS、JavaScript 製作的方塊堆疊遊戲，支援桌面鍵盤與手機觸控，並透過 GitHub Pages 發佈。

## 遊戲特色

- 從首頁開始，完整遊玩、暫停、結算與重新開始流程。
- 左右移動、旋轉、加速下降與直接落下，搭配下一塊預覽。
- 消除行數、速度、等級、遊玩時間和分數即時顯示；每五行提升速度，並在瀏覽器記錄最高分。
- 針對手機調整遊戲版面與觸控按鈕。

## 操作

- ← →：移動方塊
- ↑：旋轉方塊
- ↓：加速下降
- Space：直接落下
- P：暫停或繼續
